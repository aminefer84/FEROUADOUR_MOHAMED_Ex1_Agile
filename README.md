###Question 1
Reponse 
 Projet est un ensemble des action possède un objectif précis avec une date de début et autre de fin et produit un résultat spécifique.
 Partie prenante c’est les presonnes qui impacter au projet.
 Contrainte d’un projet est une limite ou une condition que le projet doit respecter.

###Question 3
Reponse
Une activité quotidienne est une tâche régulière et répétitive. par contre un projet est temporaire avec un objectif précis et produit un résultat spécifique.
Par exemple, créer un site web est un projet, alors que mettre régulièrement son contenu à jour est une activité quotidienne.
